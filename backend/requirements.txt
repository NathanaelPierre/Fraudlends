# pocketsphinx is COMMENTED OUT BY DEFAULT — it needs to compile C code
# at install time, which fails on Windows unless Microsoft's C++ Build
# Tools are installed (a multi-GB download most machines won't have:
# https://visualstudio.microsoft.com/visual-cpp-build-tools/, check
# "Desktop development with C++"). Without it, `pip install -r
# requirements.txt` fails entirely for everyone, even those who don't
# need speech-to-text. Uncomment the line below ONLY if you've
# installed the Build Tools (Windows) or are on Linux/macOS, where it
# installs without any extra setup:
# pocketsphinx>=5.0.0
#
# With this line commented out, POST /checks/from-audio will fail at
# runtime with an import error — every other endpoint (text, URL,
# image input, TTS, auth, admin) is completely unaffected.
#
# pocketsphinx is a fully local/offline speech recognition engine — no
# external API call. Its accuracy is meaningfully lower than a modern
# neural model (see app/stt.py's module docstring for specifics found
# during testing); swapping to openai-whisper is a worthwhile upgrade
# if disk space allows (Whisper + its dependencies need several GB).
